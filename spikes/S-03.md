# S-03  Creating users and managing groups from Apps Script with a limited admin role

## Inputs
- Custom admin role box-directory-operator assigned to the service user

## Outputs
- spikes/findings/S-03.md

## Steps
1. From an Apps Script web app executing as the service user, call the Admin SDK Directory advanced service to create a test user in /People.
2. Add and remove the user from a role group and an access group.
3. Suspend the user.
4. Attempt to grant an admin role and to read another user's mail; both must fail.
5. Record required OAuth scopes and any admin-console consent needed.
6. Write the finding.

## Human steps
- None.

## Exit criteria
- Create, group add, group remove and suspend succeed.
- Privilege-escalation attempts fail.
- Scopes are listed in the finding.

## Evidence
- setup-status.json entry with commit reference
