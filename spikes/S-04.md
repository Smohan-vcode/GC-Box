# S-04  Policy API coverage and Apps Script quotas

## Inputs
- runbooks/00-bootstrap.md

## Outputs
- spikes/findings/S-04.md
- expected-state/policy-api-coverage.yaml

## Steps
1. For each setting M-10 to M-44, query the Cloud Identity Policy API and record whether the value is returned.
2. Write expected-state/policy-api-coverage.yaml: setting id, readable true or false, API path.
3. List Apps Script quotas for the edition: script runtime, triggers, mail sent, URL fetches, document creations.
4. Estimate daily use from: 4 scans per hour, 50 documents per month, 200 inbound mails per day.
5. Write the finding with any quota within a factor of five of the estimate.

- Coverage file lists every M-xx setting.
