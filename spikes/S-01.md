# S-01  Word to Google Docs conversion and bracket location

## Inputs
- content/legal-pack/brackets.csv
- The pack's .docx files uploaded to the test tenant's intake folder

## Outputs
- spikes/findings/S-01.md
- spikes/s01_convert.gs (throwaway)

## Steps
1. Convert PS-MNDA, PS-CSA, PS-DPA and PS-IMP-DE to Google Docs with the Drive API.
2. Export each converted Doc to PDF and compare page count and table count with the pack's PDF.
3. For each file, walk the document body including tables, headers and footers, and list every bracket with its occurrence index.
4. Compare the list with brackets.csv for that code: same texts, same counts, same order.
5. Replace three occurrences by index with test values using a text range that preserves formatting; confirm neighbouring text and table layout are unchanged.
6. Test a bracket split across two text runs and a nested bracket such as `[USD [amount]`.
7. Write the finding: works, works with stated limits, or fails; include the replacement method chosen.

## Human steps
- None.

## Exit criteria
- All four files: bracket list equals brackets.csv for that code.
- Replacement by occurrence index changes only the targeted occurrence.
- Finding file states the method T6-02 and T6-05 must use.

- setup-status.json entry with commit reference
