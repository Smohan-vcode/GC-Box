# T6-04  Company data screen

## Inputs
- company.yaml > data
- content/legal-pack/dictionary.yaml

## Outputs
- Company data screen
- engine/cockpit/dictionary.js
- nightly export

## Steps
1. Seed Dictionary on first run from company.yaml > data and the dictionary seed; never overwrite a value that exists.
2. List entries with status, owner and the number of templates using each; open items first.
3. Edit shows an impact preview: templates, SENT documents and current notices that use the key.
4. Saving sets status and effective date, writes an Events row, flags affected SENT documents as stale_data and queues affected notices (T6-06).
5. Values per language where a template's language is not English.
6. Completeness view: per template, bound total, confirmed, outstanding; per key, templates unlocked.
7. Nightly export of the dictionary to the evidence folder.

## Human steps
- None.

## Exit criteria
- Changing the postcode lists every template bound to it before saving.
- A template whose keys are all CONFIRMED shows READY; one PROVISIONAL key shows INCOMPLETE.
- Seeding twice changes nothing.

## Evidence
- setup-status.json entry with commit reference
