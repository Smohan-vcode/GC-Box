# T9-04  Meeting filing

## Inputs
- Calendar events with the meetings group as guest

## Outputs
- engine/cockpit/jobs/meetings.js

## Steps
1. Nightly, for each host in the sales access group: find Meet notes, transcripts and recordings created that day.
2. Match to a counterparty by external attendee domain; unmatched go to a review list.
3. Move files to the account's Meetings folder; insert a Meetings row.
4. Never overwrite suggested_* columns written by assistant A3.

## Human steps
- None.

## Exit criteria
- A test meeting's files are in the account folder next morning with a Meetings row.
- An unmatched meeting is listed, not filed.

## Evidence
- setup-status.json entry with commit reference
