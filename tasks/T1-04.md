# T1-04  Send-as identities and Gmail filters

## Inputs
- directory/send-as.yaml
- directory/groups.yaml (label, skip_inbox)

## Outputs
- engine/cli/gmail.py
- command: box apply gmail

## Steps
1. For each user, create send-as entries for the listed groups, treated as alias.
2. Create one label and one filter per group the user belongs to: match list address, apply label, skip inbox where set.
3. Remove filters and send-as entries created by this tool that are no longer in configuration; never touch others.

## Human steps
- None.

## Exit criteria
- Founder can select each listed role address as sender.
- Test mail to two groups arrives labelled.
- Second apply reports no changes.

## Evidence
- setup-status.json entry with commit reference
