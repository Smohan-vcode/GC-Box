# T4-03  Authorisation

## Inputs
- defaults/roles.yaml

## Outputs
- engine/cockpit/auth.js

## Steps
1. Resolve the signed-in user from Session; load roles from role-group membership with a five-minute cache; apply active delegations.
2. `require(permission)` on every server action; actions without a declared permission fail the build.
3. Company-domain rows are filtered out of every query unless the user has company.read.
4. Return the user's permissions to the client only to hide controls; never trust the client.

## Human steps
- None.

## Exit criteria
- A user without company.read receives no company-domain row from any action (test for each list action).
- Calling an owner action as a non-owner is refused and logged.

- setup-status.json entry with commit reference
