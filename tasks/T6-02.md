# T6-02  Bracket extraction and suggested classification

## Inputs
- content/legal-pack/brackets.csv
- spikes/findings/S-01.md

## Outputs
- engine/cockpit/brackets.js
- Bindings rows

## Steps
1. For each new template, extract every bracket occurrence with index and 60 characters of context each side, covering body, tables, headers and footers.
2. Insert one Bindings row per occurrence with kind `unclassified`.
3. If the deployment supplies brackets.csv, copy suggested_kind and suggested_key for matching code, text and occurrence.
4. Otherwise apply the built-in rules: note words; known constant labels from the dictionary; reference tokens adjacent to the reference pattern; ` / ` or sentence-length text as choice; else deal.
5. Set Templates.brackets_total.

## Human steps
- None.

## Exit criteria
- Bindings row count per template equals the count in brackets.csv for that code (358 in total for the first pack).
- Every row has a suggested_kind.
- Re-running adds no rows.

- setup-status.json entry with commit reference
