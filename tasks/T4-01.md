# T4-01  Apps Script project, deployment and web app shell

## Inputs
- engine/register/schema.yaml
- expected-state/ids.json

## Outputs
- engine/cockpit/ (appsscript.json, Code.js, ui/)
- command: box apply cockpit

## Steps
1. Create the Apps Script project owned by the service user; manifest with V8, time zone from configuration, web app executing as the service user, access limited to the domain, and the minimal scopes listed in engine/cockpit/SCOPES.md.
2. Deploy with clasp from the pipeline; store the deployment id in expected-state/ids.json.
3. Serve a single-page shell with left navigation for the screens in SPEC section 11; each screen is a stub.
4. Write script properties from configuration: workbook id, folder ids, environment.
5. Client calls go through one `api(action, payload)` function to `google.script.run`; the server dispatches by action name.

## Human steps
- Authorise the script's scopes once as the service user.

## Exit criteria
- The web app URL opens for a domain user and is refused for an outside account.
- Navigation shows all screens.
- Redeploy keeps the same URL.

## Evidence
- setup-status.json entry with commit reference
