# T9-03  Campaigns and leads

## Inputs
- Campaigns, Leads tabs

## Outputs
- Campaigns screen
- Leads list

## Steps
1. Register a campaign: name, objective, audience, channel, dates, budget, owner; generate a unique tracking code.
2. lead.create carries campaign_code; unknown codes are stored and flagged.
3. Campaign view: leads, meetings, documents sent, orders executed, by joining on counterparty and campaign.
4. Document the website form change needed to pass the code (outside this repository).

## Human steps
- None.

## Exit criteria
- Three leads posted with a code appear under that campaign.
- An order executed for one of them is counted once.

## Evidence
- setup-status.json entry with commit reference
