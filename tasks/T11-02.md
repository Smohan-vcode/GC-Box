# T11-02  Evidence collectors

## Inputs
- defaults/controls.yaml sources named collector.*

## Outputs
- engine/cli/collectors/
- pipeline schedule

## Steps
1. One collector per source: users_2sv, admin_roles, drive_permissions, allowed_apps, mail_auth, pull_requests, drift, audit_logs, acknowledgements, checklists, approvals.
2. Each writes a dated file to the evidence folder and posts an Evidence row through the inbound endpoint.
3. Schedules follow each control's frequency.

## Human steps
- None.

## Exit criteria
- Running all collectors on the test tenant creates one artefact and one Evidence row per automated control.
- Re-running in the same period adds no duplicate row.

## Evidence
- setup-status.json entry with commit reference
