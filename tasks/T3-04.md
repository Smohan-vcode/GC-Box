# T3-04  Register workbook

## Inputs
- engine/register/schema.yaml

## Outputs
- command: box apply register
- Workbook `Register` in 90 Admin/Register

## Steps
1. Create the workbook if absent; one tab per schema tab; header row from column names plus created_at and updated_at.
2. Apply data validation for enum and bool columns; protect header rows; restrict edit access to the service user.
3. `box check register` compares the live workbook with the schema and reports missing or extra tabs and columns.
4. Adding a column in the schema adds it on apply; removal is never automatic.
5. Seed Config, Packages, PackageItems and Controls from configuration and defaults.

## Human steps
- None.

## Exit criteria
- All tabs and columns match the schema.
- Second apply reports no changes.
- Only the service user can edit.

## Evidence
- setup-status.json entry with commit reference
