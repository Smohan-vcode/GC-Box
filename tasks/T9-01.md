# T9-01  Quotations and order forms

## Inputs
- Catalogue entries with action call_order_system
- runbooks M-32

## Outputs
- Orders screen (list)
- approval rule for value threshold

## Steps
1. Order-form templates capture plan, price, currency, billing period as fields mapped to Orders columns.
2. Seed a value_above rule for the finance-approver role with the threshold left empty and inactive until the owner sets it.
3. Register M-32 (quotation copy rule) as a manual step and verify with a probe message that the quotes group receives a copy.

## Human steps
- Create the Gmail compliance rule (M-32).

## Exit criteria
- An order form above the threshold is held for finance approval.
- A probe with a bracketed reference in the subject is copied to the quotes group.

## Evidence
- setup-status.json entry with commit reference
