# T2-03  Address probe test

## Inputs
- directory/groups.yaml

## Outputs
- command: box probe mail

## Steps
1. Send one message to every mail group address and alias from the service user with a unique token.
2. Within ten minutes confirm each token arrived in a member mailbox with the right label.
3. Send one message from an external test mailbox if configured; verify SPF, DKIM and DMARC pass in the received headers.
4. Write the result table to evidence.

## Human steps
- None.

## Exit criteria
- Every address and alias is delivered and labelled.
- Authentication results show pass for all three.

## Evidence
- setup-status.json entry with commit reference
