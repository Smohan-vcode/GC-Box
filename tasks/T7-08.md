# T7-08  Counterparties and external paper

## Inputs
- Counterparties tab

## Outputs
- Counterparties screen
- Record external paper action

## Steps
1. Create and edit counterparties; show documents and NDA status; create the account folder on first use.
2. Record external paper: upload the counterparty's document, choose the nearest document code, create an EXTERNAL_PAPER row and open approval.
3. Sharing check helper: `ndaInForce(counterpartyId)` for use by other modules.

## Human steps
- None.

## Exit criteria
- An external-paper record follows EXTERNAL_PAPER, IN_REVIEW, READY, SENT, EXECUTED.
- ndaInForce is false after expiry.

## Evidence
- setup-status.json entry with commit reference
