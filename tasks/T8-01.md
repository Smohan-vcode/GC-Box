# T8-01  Setup steps in the register

## Inputs
- setup-status.json
- tasks/, spikes/, runbooks/rendered/

## Outputs
- engine/cockpit/setup.js
- command: box sync setup

## Steps
1. `box sync setup` posts every task, spike and manual item to the Setup tab through the inbound endpoint: id, track, title, kind, status, evidence, blocks, stage.
2. The cockpit imports setup-status.json once; afterwards the pipeline updates rows after each apply.
3. Stage for each step from a map in defaults/stages.yaml.

## Human steps
- None.

## Exit criteria
- Setup has one row per task, spike and M-xx item.
- A task completed in the pipeline shows DONE within one run.

## Evidence
- setup-status.json entry with commit reference
