# T0-04  Pipeline: validate, plan, apply, weekly drift skeleton

## Inputs
- .github/workflows/

## Outputs
- validate.yml, plan.yml, apply.yml, drift.yml

## Steps
1. validate.yml on pull request: box validate, check-literals, pytest, terraform validate, Node tests.
2. plan.yml on pull request: terraform plan for each module; `box plan` dry run for scripted tiers; post the summary as a comment.
3. apply.yml on merge to main: apply for the environment in company.yaml; require approval for `live`.
4. drift.yml weekly: placeholder job that calls `box drift` (implemented in T8-03).

## Human steps
- None.

## Exit criteria
- A pull request that breaks the schema fails validate.yml.
- A merge with environment live waits for approval.

## Evidence
- setup-status.json entry with commit reference
