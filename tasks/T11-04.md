# T11-04  Inventories and system description

## Inputs
- Risks, Assets, Vendors tabs

## Outputs
- Compliance screen (inventories)
- command: box render system-description

## Steps
1. Simple list and edit screens for risks, assets and vendors; vendors link to their executed agreement.
2. Render a system description draft from configuration: company, people and roles, drives, groups, controls.

## Human steps
- None.

## Exit criteria
- A vendor without an executed agreement is flagged.
- The description renders with no unresolved placeholder.

## Evidence
- setup-status.json entry with commit reference
