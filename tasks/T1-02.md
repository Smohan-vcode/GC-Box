# T1-02  Organisational units and users

## Inputs
- directory/users.yaml
- company.yaml > workspace.org_units

## Outputs
- engine/cli/directory.py
- command: box apply users

## Steps
1. Implement idempotent creation of organisational units.
2. Implement user create or update by `id`: names, unit, licence type. New users get a random password and must change it at first sign-in.
3. Never modify users whose `super_admin` is true beyond checking they exist.
4. `--plan` prints the changes without applying.
5. Write the user list after apply to the evidence folder.

## Human steps
- None.

## Exit criteria
- Second apply reports no changes.
- Users exist in the stated units with the stated licence.
- Plan mode makes no API write.
