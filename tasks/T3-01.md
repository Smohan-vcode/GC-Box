# T3-01  Shared drives and access

## Inputs
- drive/shared-drives.yaml

## Outputs
- engine/cli/drives.py
- command: box apply drives

## Steps
1. Create each shared drive if absent; record its id in expected-state/ids.json.
2. Set members to exactly the groups listed with their roles; add the service user as manager of every drive.
3. Set external sharing per drive.
4. Export drive permissions to evidence.

## Human steps
- None.

## Exit criteria
- Drives exist with only group members and the service user.
- Second apply reports no changes.

## Evidence
- setup-status.json entry with commit reference
