# T0-02  Status store and evidence writer

## Inputs
- tasks/*.md

## Outputs
- setup-status.json
- commands: status, done, runbook

## Steps
1. Parse task front matter from tasks/ and spikes/ into a dependency graph; fail on unknown or cyclic dependencies.
2. Implement `box status`: steps by track with status, and the next runnable tasks.
3. Implement `box done <id> --evidence <path-or-url>`: refuse if a dependency is not DONE.
4. Implement `box runbook`: render runbooks/*.md with values from company.yaml into runbooks/rendered/.
5. Tests for graph errors and for refusing out-of-order completion.

## Human steps
- None.

## Exit criteria
- `box status` lists every task and spike.
- `box done T0-02` without T0-01 done is refused.
- Rendered runbook contains no unresolved braces.

## Evidence
- setup-status.json entry with commit reference
