# T7-03  Signature module: manual Google eSignature

## Inputs
- SPEC section 3

## Outputs
- engine/cockpit/signature/index.js
- engine/cockpit/signature/google_manual.js

## Steps
1. Interface: request(document) and status(document). One implementation, google_manual.
2. request: requires signature.request; returns the draft link and a panel listing signer name and address to copy; instructs the user to choose eSignature and Request signature.
3. The user confirms `I have requested signature`; the document moves to SENT with sent_at.
4. The adapter name is a Config value, so another implementation can be selected without changing callers.

## Human steps
- Request the signature in Google Docs for each document (no API exists).

## Exit criteria
- A READY document can be marked SENT only by a holder of signer.
- Callers reference only the interface (static check).
