# T11-03  Recurring control tasks

## Inputs
- Controls with source task.*

## Outputs
- engine/cockpit/jobs/controltasks.js
- Compliance screen (tasks)

## Steps
1. Create a ControlTasks row on each due date; assign to the owner role; show in My queue.
2. Closing requires an attached output; closing writes an Evidence row.
3. Overdue tasks appear on Home.

## Human steps
- None.

## Exit criteria
- A quarterly task appears on its due date and cannot be closed without an output.
