# T5-03  Delegation, leavers and membership export

## Inputs
- Delegations tab

## Outputs
- engine/cockpit/delegation.js
- nightly export job

## Steps
1. Owners create dated delegations; auth applies them; actions record actor and on_behalf_of.
2. Remove person: suspend account, revoke roles, reassign open approvals to fallback roles, open a leaver checklist.
3. Nightly: export role-group membership and RoleAssignments to the evidence folder.

## Human steps
- None.

## Exit criteria
- A delegate can approve only within the dates.
- Removing a person leaves no pending approval assigned solely to them.
- Export file exists for the previous day.

## Evidence
- setup-status.json entry with commit reference
