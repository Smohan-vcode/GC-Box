# T5-01  People and roles

## Inputs
- spikes/findings/S-03.md
- defaults/roles.yaml

## Outputs
- People and roles screen
- engine/cockpit/people.js

## Steps
1. List people with roles; add person: name, address local part, roles.
2. On add: create the account if absent using the method from S-03, add to role groups and the staff access group, insert People and RoleAssignments rows, open a joiner checklist.
3. Assign and revoke a role on an existing person: group membership change plus RoleAssignments row.
4. All actions require people.manage; each writes an Events row.
5. Show a notice that a new account is a paid seat before confirming.

## Human steps
- None.

## Exit criteria
- Adding a person creates the account, memberships and rows; repeating it changes nothing.
- Revoking a role removes group membership within one run.
- A non-owner cannot call any of these actions.

## Evidence
- setup-status.json entry with commit reference
