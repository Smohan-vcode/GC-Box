# T8-03  Weekly checks and drift

## Inputs
- expected-state/
- engine/cli checks

## Outputs
- command: box drift
- .github/workflows/drift.yml

## Steps
1. `box drift` runs: terraform plan for dns and groups (role membership ignored); users, group settings, send-as, drives, folders, register schema, baseline check.
2. Each difference becomes a line: object, expected, found.
3. Steps whose check fails become DRIFTED; the report goes to the alerts group and the evidence folder.
4. Checks that pass refresh last_checked_at.

## Human steps
- None.

## Exit criteria
- Changing a group setting by hand is reported in the next run and the step shows DRIFTED.
- A clean tenant yields an empty report.

## Evidence
- setup-status.json entry with commit reference
