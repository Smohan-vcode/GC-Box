# T1-03  Groups, settings, aliases and role groups

## Inputs
- directory/groups.yaml
- defaults/roles.yaml

## Outputs
- engine/terraform/groups/
- engine/cli/groups.py
- command: box apply groups

## Steps
1. Generate Terraform for group existence and membership of mail and access groups using the google provider's Cloud Identity resources.
2. Generate role groups `role-<name>` from defaults/roles.yaml; seed membership from users.yaml once, then mark membership as externally managed (lifecycle ignore).
3. Apply group settings and aliases with GAM: posting, archive, collaborative inbox, join policy.
4. Write default auto-reply texts to content/auto-replies/ if absent.
5. Export all groups, settings and members to the evidence folder.

## Human steps
- None.

## Exit criteria
- Every group in groups.yaml exists with the stated settings and aliases.
- Second apply reports no changes.
- Changing a role group's membership by hand is not reverted by the next apply.

## Evidence
- setup-status.json entry with commit reference
