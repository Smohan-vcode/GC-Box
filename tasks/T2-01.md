# T2-01  DNS records

## Inputs
- company.yaml > dns
- DKIM value from M-30

## Outputs
- engine/terraform/dns/
- command: box dns set-dkim

## Steps
1. Terraform for the zone: MX smtp.google.com priority 1; SPF `v=spf1 include:_spf.google.com -all`; DKIM google._domainkey; DMARC from a variable `dmarc_policy` starting at none with rua to the DMARC group; TLS-RPT; CAA; `v=spf1 -all` and DMARC reject on non_mail_hosts.
2. Sending subdomains: variables for provider SPF and DKIM values; DMARC reject.
3. Fail the plan if the zone has Cloudflare Email Routing enabled.
4. Domain aliases: reject records for each.

## Human steps
- Generate the DKIM key and start signing (M-30, M-31).

## Exit criteria
- `dig` returns each record as specified.
- Plan fails with a clear message when Email Routing is on.
- Second apply reports no changes.

## Evidence
- setup-status.json entry with commit reference
