# T4-02  Data access module and events

## Inputs
- engine/register/schema.yaml

## Outputs
- engine/cockpit/data.js
- engine/cockpit/events.js
- Node tests

## Steps
1. Generate a column map from schema.yaml at build time into engine/cockpit/schema.gen.js.
2. Implement get, find, insert, update for each tab with type coercion, required-field checks, enum checks and LockService around writes.
3. Refuse update and delete on tabs marked append_only.
4. Implement `transition(entity, id, toState, actor, detail)`: checks the allowed transitions in SPEC section 7, writes the row and one Events row in the same lock.
5. Refuse any write to a suggested_* column unless the caller passes source `assistant`, and refuse an `assistant` caller writing any other column.
6. Node tests against an in-memory sheet fake.

## Human steps
- None.

## Exit criteria
- Tests cover: required check, enum check, illegal transition refused, append-only refused, suggested-column rule.
- No other module calls SpreadsheetApp (static check in the pipeline).
